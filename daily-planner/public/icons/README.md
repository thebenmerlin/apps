# App Icons

This directory should contain app icons in the following sizes for PWA and Android:

- icon-72x72.png
- icon-96x96.png
- icon-128x128.png
- icon-144x144.png
- icon-152x152.png
- icon-192x192.png
- icon-384x384.png
- icon-512x512.png

You can generate these icons from a single source image using tools like:
- https://realfavicongenerator.net/
- https://pwa-asset-generator.dev/
- https://www.favicon-generator.org/

For now, use placeholder icons or create simple colored squares with your app initials.
